# MozImage

![alt text](docs/logo_Zachary_02.png)

## Disclaimer

This project is no longer actively maintained. The code is preserved here as a historical archive — a small piece of the Mozilla extension ecosystem that once was. It is unlikely to work with any modern version of Firefox, but it remains available for anyone curious about how extensions were built in that era.

---

In 1998, *Netscape* decided to open-source its internet application suite. From the combination of *Mosaic* (the first graphical browser) and *Godzilla*, **Mozilla** was born, and from its ashes, a few years later, **Firefox** emerged.

Around 2005, I came across this O'Reilly book: "*Creating Applications with Mozilla*" and decided to try writing a small test app. Since I needed a program to browse through the photos on my machine, I decided to build something like that. That's how **mozImage** was born.

Initially it was meant to be just a personal tool, but having always been passionate about Open Source, I decided to release it on **Mozdev.org** (a sort of *GitHub* for Mozilla-related extensions). In a short time the software gained a fair amount of popularity, and I received several bug fixes, new features, and translations into **11 languages**.

Development continued for a few years (see [ReleaseNotes](https://github.com/lminuti/mozimage/wiki/ReleaseNotes)), but gradually interest faded and I abandoned the project. In 2013, a user contacted me asking to add support for newer versions of *Firefox*. *Mozdev* no longer existed by then, so I moved the code to *Bitbucket*. Once I uploaded the app to Mozilla's servers, several issues were flagged: in the meantime, the rules for writing extensions had become stricter, but I decided to push forward anyway (see: [TODO](https://github.com/lminuti/mozimage/wiki/TODO)).

I continued development for about a year, but by then there was very little interest left and downloads were just a handful, so I abandoned the project once again.
